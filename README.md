## How I approach the work

- Start with the business question and define the data grain and metric denominators.
- Make data-quality issues visible through checks, traceable corrections and explicit exclusions.
- Translate analysis into a decision, including assumptions and operational trade-offs.
- Treat product ideas as hypotheses to validate with users and stakeholders.

All five projects use synthetic data and demonstrate methods rather than measured employer outcomes. They contain no confidential client, university or municipal records. Power BI work is represented by model guidance, DAX examples and exported figures; the meeting prototype does not claim a live AI or municipal deployment.

Each repository includes reproducible setup instructions, generated outputs, tests, documentation and an MIT license. Start with **Industrial Asset Data Analytics** for the closest connection to my professional experience.
